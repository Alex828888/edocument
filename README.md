# Profile Card Mockup

Open `index.html` in a browser.

To change text, edit `app.js`:

```js
const profile = {
  topText: "Ваш текст тут",
  birthDate: "07.09.2009",
  profileId: "4006214373",
  nameLines: ["", "", ""],
};
```

To change the image, click the photo area in the page and choose a picture, or replace `assets/profile.svg` and update the `src` in `index.html`.

This is a non-official visual mockup.
